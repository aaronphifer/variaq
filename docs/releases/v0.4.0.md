# VariaQ 0.4.0 release notes

## Summary

VariaQ 0.4.0 expands from a MaxCut-only research harness into a
domain-neutral optimization platform with three new generic problem families, a
public Domain Adapter SDK, and a clean path toward backend-neutral quantum
execution.

## New problem families

- **Assignment** — generic tasks/resources with per-pair score/cost, prohibited
  pairs, capacities, and demands.
- **Subset Selection** — bounded candidate selection with value, cost, budget,
  cardinality bounds, and pairwise interactions.
- **Graph Partitioning** — k-way weighted graph partitioning with optional size
  balance constraints.

Each family includes:

- canonical problem definition,
- deterministic identity,
- serialization/deserialization,
- validation,
- authoritative evaluation,
- exact reference solver,
- seeded heuristic,
- deterministic reference generator,
- optional backend-neutral binary quadratic lowering.

## Solver support matrix

| Solver       | MaxCut | Assignment | Subset Selection | Graph Partition |
|--------------|--------|------------|------------------|-----------------|
| exact        | yes    | yes        | yes              | yes             |
| heuristic    | yes    | yes        | yes              | yes             |
| qaoa         | yes    | no         | no               | no              |
| cudaq-cpu    | yes    | no         | no               | no              |
| cudaq-gpu    | yes    | no         | no               | no              |

## Domain adapters

External projects can now write a `DomainAdapter` to translate their objects
into VariaQ problems and VariaQ results back into project terms. VariaQ core
remains domain-neutral. A CLI command scaffolds a tiny adapter template.

## Compatibility

- Output schema version remains `"1"`.
- Problem artifact format version remains `1`.
- Existing MaxCut workflows, SQLite records, and QAOA numerics are unchanged.
- No physical QPU is invoked.

## Recommended next milestone

VariaQ 0.5 should generalize QAOA over the binary quadratic lowering for the new
families and add reproducible reporting/visualization, building directly on the
0.4 foundation.
