# VariaQ 0.3.0 release notes

VariaQ 0.3.0 ships a versioned, machine-readable CLI contract on top of the
existing MaxCut solver stack.

## Included

- Output schema version `"1"`, independent of the package version (`0.3.0`).
- `--json` structured output for:
  - `solve`
  - `benchmark`
  - `compare quantum`
  - `capabilities`
  - `runs list` / `runs show` / `runs reproduce`
  - `problem generate` / `problem show`
- `variaq capabilities` command with human and JSON reporting of:
  - solver `supported` / `installed` / `available` states
  - Qiskit and CUDA-Q framework versions and targets
  - explicit `physical_qpu: not supported` reporting
- Normalized errors and warnings inside the JSON envelope.
- Preserved exit codes: `0` success/partial, `1` solver/runtime failure,
  `2` usage/input/lookup error.
- Environment-difference reporting in `runs reproduce --json`.
- Cross-platform serialization hardening: NumPy scalar normalization,
  non-finite float rejection, deterministic key ordering.
- New tests for JSON contracts, capabilities, and failure paths.
- Windows portability CI workflow.

## Compatibility

- No solver mathematics were changed for MaxCut.
- Existing SQLite databases remain readable without migration.
- Existing MaxCut Qiskit and CUDA-Q behavior is unchanged.
- No physical QPU support is added.

## Limitations

- MaxCut remains the only problem family.
- APIs are pre-1.0.
- GPU results remain best-effort reproducible across driver versions.

## Known reference values

On the deterministic 8-node MaxCut problem generated with
`--nodes 8 --edge-probability 0.4 --seed 42` and QAOA `p=1`, 32 optimizer trials,
1024 shots, seed 42:

| Solver        | Optimized expectation |
|---------------|-----------------------|
| qaoa          | 9.351891736285477     |
| cudaq-cpu     | 9.351891736285506     |
| cudaq-gpu     | 9.351890395774717     |

These are local ideal simulators; they do not demonstrate quantum advantage.

## Installation

```bash
pip install variaq==0.3.0
```

For quantum extras:

```bash
pip install variaq[quantum,cudaq]==0.3.0
```

See the README and `docs/structured-output.md` for the full CLI contract.
