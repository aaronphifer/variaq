# VariaQ 0.2.0 release notes — draft

VariaQ 0.2.0 is the planned first public release of the local-first,
reproducible hybrid-compute platform formerly developed internally as Q-Lab.

## Included

- weighted MaxCut generation, serialization, evaluation, and validation;
- exact enumeration and seeded local search;
- Qiskit local statevector QAOA;
- CUDA-Q `qpp-cpu`, `nvidia`, and `nvidia-fp64` adapters;
- matched QAOA candidates and canonical variable normalization;
- normalized objectives, gaps, timing, backend metadata, and status;
- append-only SQLite storage, deterministic connection cleanup, and rerun lineage;
- deterministic benchmark and scaling configurations.

For the tested 8-node problem, Qiskit and CUDA-Q CPU both found objective 12.
The maximum expectation difference across 32 identical vectors was about
`2.84e-14`. This validates the tested implementations within floating-point
tolerance; it does not demonstrate quantum advantage.

## Limitations

- MaxCut is the only problem family.
- quantum execution is local ideal simulation;
- NVIDIA support was not physically exercised because the host exposed zero
  compatible devices;
- APIs are pre-1.0;
- no real-QPU path exists.

Experiments and records remain local, with no credential, telemetry, account,
or network requirement for normal tests. This is a draft only; no tag or
GitHub release has been created.
